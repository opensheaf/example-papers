# TeXmacs examples from tm-forge

These files are copied unchanged from [tm-forge](https://github.com/texmacs/tm-forge),
the TeXmacs project's repository of user-contributed content (commit 635bd57),
which is distributed under the GNU General Public License, version 3: see its
[LICENSE](https://github.com/texmacs/tm-forge/blob/main/LICENSE). They keep
that licence here, and their deposits say so.

- `ibp-exponential/`: F. C. De Vecchi, M. Gubinelli, M. Turra, *A singular
  integration by parts formula for the exponential Euclidean QFT on the
  plane* (tm-forge `examples/papers-gubinelli/`).
- `meyer-cdt-slides/`: S.-J. Meyer, *A forward-backward approach to
  stochastic quantisation*, slides (tm-forge `examples/slides-meyer-cdt/`),
  with the style `metropolis.ts`.
- `audoly-mec430/`: B. Audoly, *Mécanique des milieux déformables*, MEC 430,
  lecture 8, slides (tm-forge `examples/lecture-slides-audoly/`), with the
  style `slides_mec430.ts` and 14 figures in `imgs/`.

Each is deposited with its TeXmacs source and the PDF found in tm-forge (no
typesetting needed); see `../deposits/`.
